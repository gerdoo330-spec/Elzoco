راهنمای نسخه‌ی کامل بازطراحی‌شده‌ی سامانه‌ی الزوکو
====================================================

این بسته شامل کل فایل‌های برنامه است، نه فقط فایل‌های ظاهری.

بازطراحی رابط کاربری
--------------------
- یکپارچه‌سازی ظاهر ورود کارکنان و ورود مدیران
- بهبود داشبورد و کارت‌های آماری مدیر
- نظم‌دهی جدول‌ها، فیلترها، فرم‌ها، دکمه‌ها و پنجره‌های محاوره‌ای
- بهبود پنل کارمند، اطلاعات شخصی، تب‌ها و فرم‌های مساعده، وام، مرخصی و ارتقا
- یکپارچه‌سازی ظاهر حساب‌های مدیریت، بازه‌های زمانی، قوانین مالی و گردش تأیید
- بهبود نمایش صفحات چاپی در مرورگر با حفظ قالب چاپ A4
- افزودن فایل assets/experience-ui.css به‌عنوان لایه‌ی طراحی مشترک
- بهبود واکنش‌گرایی برای دسکتاپ، تبلت و موبایل

نصب روی هاست
-------------
1) قبل از جایگزینی، از پوشه‌ی فعلی سایت و دیتابیس نسخه‌ی پشتیبان بگیرید.
2) ZIP را در پوشه‌ی اصلی سامانه در cPanel بارگذاری و Extract کنید؛ پوشه‌های admin، api، assets، db، src و storage باید کنار index.php باشند.
3) فایل config.php را با اطلاعات اتصال دیتابیس فعلی هاست تطبیق دهید. مقادیر دیتابیس را از روی هاست خودتان بررسی کنید؛ به مقادیر نمونه یا مقادیر قدیمی اعتماد نکنید.
4) اگر دیتابیس قبلی وجود دارد، آن را حذف یا دوباره نصب نکنید. فایل setup.php را روی سامانه‌ی نصب‌شده اجرا نکنید.
5) پس از استخراج، صفحه را با Ctrl+F5 تازه‌سازی کنید.
6) پس از اطمینان از اجرای سامانه، فایل‌های setup.php و hash.php را از دسترس عمومی خارج یا حذف کنید.

درباره‌ی اطلاعات
----------------
این ZIP فایل‌های برنامه را شامل می‌شود، اما بکاپ داده‌های زنده‌ی MySQL نیست. اطلاعات کارکنان، درخواست‌ها و تنظیمات در دیتابیس قرار دارند. برای حفظ آن‌ها باید دیتابیس فعلی دست‌نخورده بماند یا از بکاپ SQL بازیابی شود.

کنترل‌های انجام‌شده روی این بسته
--------------------------------
- بررسی نحوی فایل‌های PHP
- بررسی نحو فایل‌های JavaScript
- بررسی ساختار CSS جدید
- بررسی سلامت آرشیو ZIP

اجرای زنده با دیتابیس واقعی و مرورگر هاست در این محیط انجام نشده است؛ بنابراین پس از نصب، ورود و ذخیره‌ی یک تنظیم آزمایشی را کنترل کنید.
