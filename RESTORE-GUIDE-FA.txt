راهنمای بازگردانی و نصب نسخه‌ی کامل سامانه الزوکو
=================================================

محتویات
-------
این بسته شامل فایل‌های کامل برنامه، پنل کارمند، پنل مدیریت، APIها، فایل‌های CSS و JavaScript، اسکریپت‌های دیتابیس و فایل‌های راه‌اندازی است. لایه‌ی طراحی مشترک جدید در assets/experience-ui.css قرار دارد.

مراحل cPanel
------------
1) در File Manager وارد پوشه‌ای شوید که سامانه از آن اجرا می‌شود (برای مثال public_html یا پوشه‌ی اختصاصی سامانه).
2) پیش از جایگزینی، از کل پوشه‌ی فعلی و دیتابیس نسخه‌ی پشتیبان تهیه کنید.
3) فایل ZIP را در همان پوشه بارگذاری و Extract کنید. فایل‌ها باید مستقیماً در ریشه‌ی سامانه قرار بگیرند؛ پوشه‌های admin، api، assets، db، src و storage باید کنار index.php باشند.
4) config.php این بسته از نسخه‌ی اصلی پروژه حفظ شده است، اما ممکن است اطلاعات اتصال آن با هاست فعلی یکسان نباشد. مقادیر host، name، user و pass را با اطلاعات دیتابیس موجود در cPanel تطبیق دهید.
5) اگر دیتابیس قبلی هنوز وجود دارد، آن را حذف، خالی یا دوباره نصب نکنید. فایل‌های SQL داخل db برای ساختار/ارتقای دیتابیس هستند و اجرای دوباره‌ی آن‌ها بدون بررسی می‌تواند مشکل ایجاد کند.
6) اگر storage/installed.lock وجود دارد، setup.php را اجرا نکنید. پس از اطمینان از اجرای صحیح سامانه، setup.php و hash.php را حذف یا از دسترس عمومی خارج کنید.
7) مرورگر را با Ctrl+F5 تازه‌سازی کنید تا فایل‌های CSS و JavaScript جدید بارگذاری شوند.

نکته مهم درباره داده‌ها
----------------------
ZIP شامل فایل‌های برنامه است، نه نسخه‌ی پشتیبان دیتابیس زنده. اطلاعات کارکنان، فیش‌ها، درخواست‌ها و تنظیمات در MySQL قرار دارند. اگر دیتابیس حذف شده باشد، باید بکاپ SQL دیتابیس را جداگانه بازیابی کنید.
